# wind-tiles

Тайлы ветра, температуры и авиационных опасностей для карты приложения Pilot Force. Источник — открытые данные прогноза ECMWF IFS (сетка 0.25°). Конвейер на Python скачивает GRIB2, режет глобальное поле на PNG-тайлы и выкладывает их на Firebase Hosting (`https://tiles.aviationweather.pro/wind/v1/`).

## Тайл

- Узлы тайла (zoom z, ряд r, колонка c): шаг s = 1° / 0.5° / 0.25° для z = 1 / 2 / 3, сторона 180·s. Юг = −90 + r·180·s, запад = −180 + c·180·s. Ряд считается от 90°S, колонка от 180°W.
- Узлы — каждый `stride` = 4 / 2 / 1 узел глобальной сетки 0.25° (1440 × 721). Восточный край последней колонки (180°) — это колонка −180°. Верхний край верхнего ряда — 90°N.
- Тайлов на уровень и кадр: 2 (z = 1), 8 (z = 2), 32 (z = 3).
- Уровни: `sfc` (10 м, 2 м), 850, 700, 500, 400, 300, 250, 200, 150 hPa.
- PNG RGB 8 бит, 181 × 182, без альфы и без цветовых чанков (sRGB, gAMA, iCCP).
  - Строка 0: пиксели 0…7 несут 24 байта = `struct.pack("<6f", uMin, uMax, vMin, vMax, tMin, tMax)` по R, G, B подряд. Остальное — нули.
  - Строки 1…181: узлы с севера на юг, в строке с запада на восток. R = u (kt), G = v (kt), B = T (°C).
  - Байт 0 во всех трёх каналах — нет данных (любое из u, v, T = NaN). Данные: `b = 1 + round((x − min) / (max − min) · 254)`; при max = min `b = 1`. Обратно: `x = min + (b − 1) · (max − min) / 254`. Ошибка ≤ (max − min) / 508: для струи −80…+220 kt — 0.6 kt.
- Путь: `wind/v1/{run:yyyyMMddHH}/{frame:yyyyMMddHH}/{sfc|850|…|150}/{z}/{r}/{c}.png`.

## Тайлы опасностей

Формат и сетка — как у тайла ветра (заголовок min/max, байт 0 — нет данных), тот же прогон, кадры и манифест.

- Путь: `hazards/v1/{run:yyyyMMddHH}/{frame:yyyyMMddHH}/{850|700|500|400|300|250|200|150|col}/{z}/{r}/{c}.png`.
- Уровень hPa: R = `S` турбулентности (Ellrod TI1, сдвиг ветра к соседним уровням по `gh`), G = `S` обледенения (T и RH, максимум 0.7), B = изотерма 0° — эшелон (FL, ISA) самого нижнего перехода через 0 °C над землёй, 0 при `2t` ≤ 0 °C. Под землёй (`sp` < L × 100 Па) и полярнее ±85° (турбулентность) — нет данных.
- `col`: R = `S` грозы (√ произведения факторов MUCAPE и темпа), G = MUCAPE, J/kg, B = темп конвективных осадков за 3 ч, mm/h (разность накопленного `cp`; кадру 6 нужен `cp` шага 3). Все три канала расширены на ±0.5° — максимум по ±2 узлам 0.25° до нарезки, на всех зумах: карточка показывает самые сильные значения в пределах ~30 NM.
- `S` — тяжесть 0…1, одна шкала: `≥ 0.25` слабая, `≥ 0.5` умеренная, `≥ 0.75` сильная. Пороги — в `windtiles/hazards.py`.
- На z = 1 и 2 каналы `S` уровней hPa берут максимум по узлам 0.25° вокруг узла (окно ±stride / 2); `S` грозы уже расширен на ±0.5° и, как остальные каналы, берётся узлом.

## Сверка

`tools/calibrate.py` (вне пакета и CI) сверяет пороги последнего прогона (шаги 6, 9, 12, 15) с PIREP/AIREP и конвективными SIGMET AWC — теми же запросами, что у приложения:

```bash
.venv/bin/python -I tools/calibrate.py --work "$TMPDIR/wx-calib"
```

- Турбулентность: отчёты MOD+ на FL200+; попадание — `S ≥ 0.25` в ±0.5° и ±1 уровень от ближайшего из 400…150 hPa в ближайшем кадре. Площадь — доля глобуса (вес `cos φ`) с `S ≥ 0.5` на 300 / 250 / 200 hPa, среднее по кадрам. Цель: ≥ 50 % попаданий при площади ≤ 10 %.
- Грозы: SIGMET TS / CONV / CB часа запроса; доля площади полигонов под `S ≥ 0.25` колонки (уже расширенного на ±0.5°) в ближайшем кадре. Цель: ≥ 60 %.

30.10.2026, прогон 2026-10-30T00Z, AWC 12:07Z: 72 PIREP/AIREP, из них MOD+ FL200+ — 5 (LGT-MOD+ — 11); 61 полигон конвективных SIGMET. Опоры не менялись; зона грозы расширена на ±0.5°.

| Опоры | MOD+ попаданий | LGT-MOD+ попаданий | Площадь `S ≥ 0.5` 300 / 250 / 200 | SIGMET под `S ≥ 0.25`: узлом → с ±0.5° |
|---|---|---|---|---|
| текущие | 4 / 5 (80 %) | 7 / 11 (64 %) | 2.3 / 2.5 / 1.3 % | 21 → 58 % |
| × 0.75 | 5 / 5 | 9 / 11 | 4.4 / 4.8 / 2.6 % | 26 → 63 % |
| × 1.5 | 4 / 5 | 7 / 11 | 0.8 / 0.9 / 0.4 % | 12 → 44 % |
| × 2 | 3 / 5 | 4 / 11 | 0.3 / 0.4 / 0.1 % | 6 → 30 % |

- Турбулентность — цель достигнута, `TI1_POINTS` остаются. Отчётов мало (5): вывод слабый, повторить на другом прогоне.
- Грозы — `CAPE_POINTS` и `RATE_POINTS` остаются: снижение порогов почти не добавляет покрытия, только шум. MUCAPE ≥ 100 J/kg покрывает 84 % площади SIGMET, а конвективные осадки ≥ 0.1 mm/h — 42 %; даже опоры × 0.25 дают 42 %. Модель ошибается в месте ячеек на десятки миль, поэтому `S` грозы расширен на ±0.5° (максимум по ±2 узлам 0.25°, `build.STORM_POOL`) до нарезки: покрытие SIGMET 21 → 58 % (цель 60 % почти достигнута), доля глобуса с `S ≥ 0.25` в кадре +12 ч — 9.4 %.

## Запуск локально

Нужен Python 3.14.

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/pip install -e .
.venv/bin/python -I -m pytest -q
```

Скачанные GRIB — недоверенные данные: держите рабочий каталог вне репозитория, Python запускайте с `-I`.

Сборка последнего прогона (без `--force` — только если он новее выложенного; в GitHub Actions — ручной запуск с флагом `force`). Зеркало ECMWF Open Data — Google Cloud (`source.SOURCE = "google"`): AWS 28.10.2026 отвечал 503 Slow Down на каждый запрос.

```bash
.venv/bin/python -I -m windtiles.build --force --out "$TMPDIR/wt/site" --work "$TMPDIR/wt/grib"
```

Замер на Mac (28.10.2026, прогон 06Z, зеркало Google): 8 мин 44 с (3.3 мин CPU, остальное — загрузка 282 MB GRIB); 7 938 тайлов, 292 MB.
